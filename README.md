# Сайт ФКМ — промышленная химия для ЦБП

Переработанная версия сайта [fkm-chemicals.ru](https://fkm-chemicals.ru). Статический сайт
без сборки и зависимостей: HTML + CSS + один файл JS. Заливается на любой хостинг
простым копированием папки.

---

## Что изменилось по сравнению со старым сайтом

| Было (Tilda) | Стало |
|---|---|
| Плоский список продуктов | Навигация «от задачи»: тиссью, упаковка, макулатура, чистота оборудования, цвет, газоразделение |
| Продукты без описаний на главной | Отдельные страницы направлений с карточками по каждому продукту и марке |
| Нет позиционирования | Акцент на техническом сопровождении и внедрении без остановки производства |
| Только контактный телефон | Формы запроса КП на каждой продуктовой странице + honeypot от спама |
| Один общий стиль Tilda | Собственная дизайн-система на фирменных цветах ФКМ (тёмно-синий + циан, гексагоны — как на выставочных стендах) |
| Нет SEO-разметки | title/description на каждую страницу, OG-теги, JSON-LD Organization, sitemap.xml, robots.txt, hreflang RU/EN |
| — | Мобильная версия, доступность (skip-link, фокус, `prefers-reduced-motion`), страница 404 |

## Что нужно сделать перед публикацией

Места, требующие вашего решения, помечены в коде комментарием `ЗАМЕНИТЬ`.

### 1. Подключить приём заявок (обязательно)

Сейчас формы работают через `mailto:` — открывается почтовый клиент посетителя.
Это рабочий, но не лучший вариант: часть заявок теряется.

Чтобы заявки приходили на почту напрямую, добавьте атрибут `data-endpoint`
в тег `<form>` на каждой странице:

```html
<form class="form form--onDark" data-form data-endpoint="/api/request">
```

Скрипт отправит `FormData` методом POST и покажет посетителю результат.
Подойдёт любой обработчик: PHP-скрипт на хостинге, Formspree, Яндекс.Формы,
готовый endpoint вашей CRM. Поле `company_website` — скрытая ловушка для ботов,
на бэкенде отбрасывайте заявки, где оно заполнено.

### 2. Уточнить цифры на главной

В блоке фактов (`index.html`, секция `.stats`) сейчас стоят только проверяемые данные:
3 направления, 8 групп химикатов, 7 производителей, РФ + СНГ. Если хотите показать
срок работы на рынке, число обслуживаемых площадок или объём складского запаса —
подставьте свои значения.

### 3. Довести политику конфиденциальности

`privacy.html` — заготовка по 152-ФЗ. Нужно подставить полное наименование
юрлица, ИНН, ОГРН, дату редакции и согласовать текст с юристом.
Пропуски отмечены как `[…]`.

### 4. Карта на странице контактов

В `contacts.html` вставлена карта Яндекса по адресу офиса. При желании замените
на конструктор карт с двумя отметками (офис + склад).

### 5. Фотографии

Все изображения взяты с текущего сайта компании. Стоит добавить свежие фото:
производственные площадки клиентов, продукцию в упаковке, команду.
Класть в `assets/img/`, для новостей — в `assets/img/news/`.

## Как редактировать

### Добавить новость

В `news.html` скопируйте любой блок `<article class="news-card">` и поправьте текст.
Если картинки нет — удалите внутри него `<div class="news-card__media">`.
Три последние новости продублированы на главной (`index.html`, секция «Выставки и события»).

### Добавить продукт

На продуктовой странице скопируйте блок `<article class="prod-item">`:

```html
<article class="prod-item" data-reveal>
  <div class="prod-item__name"><b>Название</b><span class="tag">метка</span></div>
  <p>Описание продукта.</p>
  <ul class="prod-item__specs">
    <li><span>Параметр</span><span>Значение</span></li>
  </ul>
</article>
```

`prod-item__specs` необязателен — используйте, когда есть что показать таблицей.

### Добавить целую группу продуктов

Скопируйте секцию `<section class="prod-group" id="...">` и добавьте ссылку
на её `id` в блок `<nav class="subnav">` в начале страницы — подсветка активного
пункта при скролле подхватится сама.

### Общая шапка и подвал

Сайт статический, поэтому шапка и подвал продублированы в каждом файле.
При правке меню или контактов изменения нужно внести во все `*.html`.
Быстрее всего — поиском с заменой по всей папке.

### Цвета и шрифты

Всё задано переменными в начале `assets/css/style.css` (раздел «1. Токены»).
Смена фирменного цвета — это правка `--cyan-500` и `--navy-900`, остальное подтянется.

## Публикация

Сайт не требует сборки. Скопируйте содержимое папки в корень хостинга
(`public_html`, `www` или аналог) любым FTP/SFTP-клиентом.

Рекомендуемые настройки на стороне сервера:

- HTTPS и редирект с `http://` на `https://`;
- редирект с `www.fkm-chemicals.ru` на основной домен (или наоборот — главное, один вариант);
- страница ошибки 404 → `/404.html`;
- редиректы со старых адресов Tilda, чтобы не потерять позиции в поиске:

| Старый адрес | Новый |
|---|---|
| `/pulp_industry` | `/pulp-chemicals.html` |
| `/activated_carbon` | `/carbon.html` |
| `/filters` | `/filters.html` |
| `/special_offer` | `/special-offer.html` |
| `/en` | `/en/` |

Пример для Apache (`.htaccess`):

```apache
ErrorDocument 404 /404.html
Redirect 301 /pulp_industry    /pulp-chemicals.html
Redirect 301 /activated_carbon /carbon.html
Redirect 301 /filters          /filters.html
Redirect 301 /special_offer    /special-offer.html
Redirect 301 /en               /en/
```

После публикации — отправить `sitemap.xml` в Яндекс.Вебмастер и Google Search Console.

> **Про подкаталоги.** `404.html` ссылается на ресурсы от корня сайта (`/assets/...`) —
> это правильно для боевого домена, но ломается, если выложить сайт в подпапку
> (например, GitHub Pages вида `user.github.io/fkm-site/`). Остальные страницы
> используют относительные пути и работают в подпапке нормально.

## Технические заметки

- **Зависимости:** только шрифты Google Fonts (Manrope, Inter, IBM Plex Mono).
  Если нужен сайт, работающий без внешних запросов, скачайте шрифты в `assets/fonts/`
  и замените `<link>` на локальный `@font-face`.
- **Поддержка браузеров:** современные версии Chrome, Firefox, Safari, Edge.
  Используются CSS Grid, `clamp()`, кастомные свойства, `IntersectionObserver`.
- **Без JS** сайт остаётся читаемым: анимации появления отключаются через `<noscript>`,
  вся навигация и контент доступны.
- **Доступность:** skip-link, видимый фокус, `aria`-атрибуты на меню и аккордеонах,
  учёт `prefers-reduced-motion`.
- **Логотип** — оригинальный растровый файл компании `assets/img/logo.jpg` (1000×486, с белым
  фоном). В подвале на тёмной подложке он выводится на белой плашке — иначе была бы видна
  белая заливка JPEG. Фавикон `assets/img/favicon.png` (512×512) — вырезанный гексагональный
  знак из того же файла.

  **Стоит заменить.** Растровый логотип мылит на экранах с высокой плотностью пикселей
  и не перекрашивается под тёмный фон. Если у компании есть исходник в кривых (`.ai`, `.eps`,
  `.svg`) или PNG с прозрачностью — положите его в `assets/img/` и поправьте ссылки
  (21 вхождение `logo.jpg` и 11 вхождений `favicon.png` по всем `*.html`).
